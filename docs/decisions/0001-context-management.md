# 0001. Управление контекстом проекта

- Статус: accepted
- Дата: 2026-09-05

## Контекст

Полные журналы, OCR и старые задачи быстро раздувают входной контекст агента и ухудшают поиск действующих решений.

## Решение

Держать короткий актуальный снимок в `.codex/project-memory.md`; активные задачи — в одном файле; детали — в профильных документах; завершённые задачи — в помесячном архиве. `AGENTS.md` содержит маршрутизацию, а не энциклопедию проекта.

## Последствия

Память и active необходимо обновлять при завершении значимой работы. История сохраняется, но не читается Codex автоматически.

## Альтернативы

- Один большой `PROJECT.md`: проще в начале, быстро становится дорогим и противоречивым.
- Вся история в `AGENTS.md`: автоматически загружается и постоянно расходует контекст.
