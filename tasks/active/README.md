# Активные задачи

## HACK-006 — Подключить planner/mutator сценариев

- Этап: 3 — генерация вариантов и расширение корпуса.
- Результат: OpenRouter planner/mutator предлагает schema-valid варианты payload/scenario, а deterministic runner замораживает успешные replay.
- Готово, когда: есть минимум 2-3 новых сценарных варианта C1/C2/C3 с отчетами ASR/funnel.
- Ближайшее действие: спроектировать формат seed family/mutator output без включения LLM в executor/oracle.
