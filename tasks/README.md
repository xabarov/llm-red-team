# Управление задачами

## Жизненный цикл

1. Идея без текущего обязательства попадает в `backlog.md` одной строкой.
2. В работе одновременно держим не более трёх пунктов в `active/README.md`.
3. У активной задачи должны быть результат, критерий готовности и ближайшее действие.
4. После завершения краткий итог переносится в `archive/YYYY-MM.md`; рабочие подробности не копируются.
5. Решения длительного действия выносятся в ADR или профильную документацию.

Архив не используется как память по умолчанию. Обращайтесь к нему только при конкретном вопросе об истории.
