# Глоссарий проекта

Этот файл фиксирует предпочтительную терминологию русских исследовательских
разборов. Сокращения метрик и имена систем не переводятся.

| English | Русский вариант |
|---|---|
| agent | агент |
| agent harness | агентный каркас |
| long-term memory | долговременная память |
| memory backend / store | хранилище памяти |
| memory poisoning | отравление памяти |
| prompt injection | инъекция промпта |
| payload | вредоносная нагрузка; `payload` в идентификаторах |
| write / persistence | запись / сохранение |
| recall / retrieval | вызов из памяти / извлечение |
| adoption | принятие извлечённого правила агентом |
| externalization | внешнее последствие |
| compaction | сжатие контекста |
| provenance | происхождение и цепочка доверия |
| checkpoint | контрольная точка |
| evidence bundle | пакет доказательств |
| judge | модель-судья |
| guard / gate | защитная проверка / программный барьер |
| benign preservation | сохранность полезной памяти |
| selective repair | избирательное исправление |
| attack success rate (ASR) | доля успешных атак (ASR) |
| retrieval success rate (RSR) | доля успешных извлечений (RSR) |
