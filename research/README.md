# Исследовательские материалы

## Поток обработки публикации

1. Добавить запись в `sources.yaml`: стабильный идентификатор, URL/DOI, название, авторы, год, лицензия и SHA-256 файла.
2. Сохранить исходник локально в `papers/original/` (каталог исключён из Git).
3. Проверить наличие текстового слоя через `pdftotext`; OCR применять только для страниц без пригодного текста.
4. Сохранить техническое извлечение в `papers/extracted/` (исключено из Git).
5. Прочитать PDF постранично и создать `papers/ru/PAPER_ID/summary.md`: библиография, суть, методика, результаты, ограничения, применение к хакатону и карта каждой страницы.
6. Сверить численные утверждения и термины с PDF; визуально проверить страницы с ключевыми рисунками и таблицами.

Базовое извлечение:

```bash
scripts/extract-paper.sh \
  research/papers/original/PAPER_ID.pdf \
  research/papers/extracted/PAPER_ID.txt \
  eng
```

Скрипт использует текстовый слой, если на страницу приходится не менее 100 непробельных символов; иначе запускает OCR всех страниц. Для смешанного английского и русского документа передайте `eng+rus`.

Не храните полные машинные переводы: они раздувают контекст и часто искажают
терминологию. OCR и извлечённый текст — только технические промежуточные данные.
В разбор переносите самостоятельно проверенные выводы и номера страниц.
